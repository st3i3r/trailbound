Trailbound — Phase -1 paper kit (Pinewatch Forest)

Run 10 in-game days per session, 5 sessions. Each day: Morning (read the booking board, weather) → Prep (cook, buy, place — use the journal-page unlocks; the Outfitter opens day 2) → Evening (drag guest cards onto pads; check the star preview by hand) → Night (score stars, pay fees + tips, walk-ins, page gifts; buy phase again tomorrow). Record each night on the log sheet. Compare with the sim: python tools/sim.py --show.

How a night scores (§5.4)

stars = clamp(2 + comfort + meal + traits + weather, 1, 5) · comfort: bare 0 / Platform +1 / Cabin +2 · meal: favourite +1 / other 0 / none −1 · +1 per need met, −1 per aversion · rain −1 on uncovered pads (Tarp r1, cabins always dry) · tip = fee × 10% × max(0, stars−2) · site rating = mean of last 15 reviews · walk-ins = min(Seats, ⌊rating⌋−2), each buys a leftover meal (avg 18c at Pinewatch)

Neighbour rule for this kit: pads in a row — each pad's neighbours are the pads immediately left/right (2–3 per pad, §5.1). An item "reaches" a pad when any pad cell is within Chebyshev r1 of the item cell — on paper, count the item's r as "~2 pads (r1) / ~4 pads (r2)" and place its effect chit under the pads you choose.

Board strip

Each morning line up open pads + 1 cards (+1 more on in-game weekends, days 6–7 of 7). Day 1 is scripted: two single-trait travellers. From day 6 every board must contain one conflicting pair (Social×Introvert, Loud×Light Sleeper, Night Owl×Stargazer). Families appear ~1 night in 3 once ≥4 pads open; their card stays disabled with no free pad pair. Cards left in the tray at Goodnight leave politely — no penalty.
